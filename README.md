# 📊 Swiggy Sales Dashboard (Excel Project)

## Overview

This project is an interactive Excel Dashboard developed to analyze Swiggy sales performance. The dashboard provides insights into sales trends, customer ratings, order values, and regional performance.

## Dashboard Features

* KPI Cards
* Monthly Sales Trend
* Daily Sales Trend
* Weekly Sales Trend
* State-wise Sales Analysis
* Top 5 Cities by Sales
* Veg vs Non-Veg Sales Distribution
* Interactive Filters and Slicers

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Data Visualization

## Key Metrics

* Total Sales: ₹53.01M
* Average Rating: 4.34
* Average Order Value: ₹268.51
* Total Orders: 197K+
